### 控制台
#### 1. 安装控制台
* git clone https://github.com/apache/shardingsphere-elasticjob.git
* cd shardingsphere-elasticjob
* git tag
* git checkout 2.1.5
* mvn clean package -DskipTests
* cd elastic-job-lite/elastic-job-lite-console/target
* tar -xvzf elastic-job-lite-console-2.1.5.tar.gz
* 进入shardingsphere-elasticjob\elastic-job-lite\elastic-job-lite-console\target\elastic-job-lite-console-2.1.5\bin
* 双击start.bat
* http://localhost:8899/

* 用户名：root, 密码：root

#### 2. Add registry center
* 指定name: demo
* 指定zookeeper: 192.168.1.4:2181
* 指定Namespace: elastic-job-demo

#### 3. 启动作业测试

#### 4. 打包时，必须将java版本切换为jdk8
* 右键点击“此电脑” → 选择“属性” → 点击“高级系统设置” → 在“高级”选项卡中点击“环境变量”。
