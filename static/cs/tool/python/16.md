#### 1. 文件
<pre><code style="font-size: 19px; font-family: Microsoft YaHei; line-height: 30px;">
    f = open("D:\\tmp\\a.txt", "r", encoding="utf-8")
    line = f.readline()
    while line != "":

        print(line.strip())
        line = f.readline()
    f.close()

    f = open("D:\\tmp\\b.txt", "w", encoding="utf-8")
    f.write("hello tom\n")
    f.write("good to see you again\n")
    f.write("see you later")
    f.close()
</code></pre>

#### 2. 模式
* r：读取
* w: 写入
* a: 追加写入
* r+: 读取 + 追加写入

#### 3. 样例
<pre><code style="font-size: 19px; font-family: Microsoft YaHei; line-height: 30px;">

    f = open("a", "r")
    my_map = {}
    line = f.readline()
    while line != "":
        my_map[line.strip('\n')] = 1
        line = f.readline()
    f.close()

    f = open("b", "r")
    line = f.readline()
    while line != "":
        line = line.strip('\n')
        if line in my_map:
            print(line)
        line = f.readline()
    f.close()
</code></pre>
