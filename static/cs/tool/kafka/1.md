### 快速入门
* 官网： https://kafka.apache.org/quickstart
#### 1. docker安装kafka
* docker pull apache/kafka:4.0.0

* docker run --name kafka -p 9092:9092 apache/kafka:4.0.0

#### 2. 查看topic
* docker exec -it kafka bash

* find / -name kafka-topics.sh
* /opt/kafka/bin/kafka-topics.sh --list --bootstrap-server localhost:9092

#### 3. 新建topic
* /opt/kafka/bin/kafka-topics.sh --create --topic demo-tom --bootstrap-server localhost:9092

* /opt/kafka/bin/kafka-topics.sh --list --bootstrap-server localhost:9092

* /opt/kafka/bin/kafka-topics.sh --describe --topic demo-tom --bootstrap-server localhost:9092

#### 4. 写入数据
* /opt/kafka/bin/kafka-topics.sh --describe --topic demo-tom --bootstrap-server localhost:9092

#### 5. 读取数据
* /opt/kafka/bin/kafka-console-consumer.sh --topic demo-tom --from-beginning --bootstrap-server localhost:9092
