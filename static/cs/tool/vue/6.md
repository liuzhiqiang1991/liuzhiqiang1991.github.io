#### 环境准备
#### 1. vue-cli
* Vue-cli 是Vue官方提供的一个脚手架，用于快速生成一个Vue的项目模板
* 依赖环境：Nodejs

#### 2. 安装nodejs
* 下载安装包

* 执行安装包，选择安装目录：D:\software\node
* 验证NodeJS环境变量：node -v
* 配置npm的全局安装路径，以管理员身份运行cmd:  npm config set prefix "D:\software\node"
* 验证：npm config get prefix
* 切换npm的淘宝镜像：npm config set registry https://registry.npmmirror.com

#### 3. 安装vue-cli
* npm install -g @vue/cli
* vue --version
