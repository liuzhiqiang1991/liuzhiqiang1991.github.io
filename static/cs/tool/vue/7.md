#### Vue项目

#### 1. 项目初始化
* vue init webpack vue-demo

* Install vue-router? (Y/n)  Y
* 其他全部选择 n 或者直接回车

#### 2. 目录结构
* node_modules 整个项目的依赖包
* public 存放项目的静态文件
* src 存放项目的源代码
* package.json 模块基本信息，项目开发所需要模块，版本信息
* config 保存vue配置的文件

#### 3. src目录
* assets 静态资源
* components 可重用的组件
* router 路由配置
* views 视图组件（页面）
* App.vue 入口页面（根组件）
* main.js 入口js文件

#### 4. 启动
* npm run dev
