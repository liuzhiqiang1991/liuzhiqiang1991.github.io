* vue init webpack vue-demo

* Install vue-router? (Y/n)  Y
* 其他全部选择 n 或者直接回车

#### 2. 安装ElementUI组件库
* npm install element-ui@2.15.3

#### 3. main.js, 引入ElementUI组件库
```
    import ElementUI from 'element-ui';
    import 'element-ui/lib/theme-chalk/index.css';

    Vue.use(ElementUI);
```
