### Element 快速入门
* 官网：https://element.eleme.cn/#/zh-CN
#### 1. 安装ElementUI组件库（在当前工程的目录下）, 在命令行执行指令
* npm install element-ui@2.15.3
#### 2. main.js, 引入ElementUI组件库
```
    import ElementUI from 'element-ui';
    import 'element-ui/lib/theme-chalk/index.css';

    Vue.use(ElementUI);
```

#### 3. 测试
#### 3.1 新增 components/element/ElementDemo.vue
```
    <template>
      <div>
        <el-row>
          <el-button type="primary">主要按钮</el-button>
          <el-button type="success">成功按钮</el-button>
        </el-row>
      </div>
    </template>
```

#### 3.2 HelloWorld.vue
```
    <template>
      <div class="hello">
        <element-demo/>
      </div>
    </template>

    <script>
    import ElementDemo from './element/ElementDemo'
    export default {
      name: 'HelloWorld',
      components: {
        ElementDemo
      },
      data () {
        return {
          msg: 'Welcome to Your Vue.js App'
        }
      }
    }
    </script>
```
#### 3.3 npm run dev
