### 安装
#### 1. 解压apache-maven-3.6.1-bin.zip
#### 2. 配置本地仓库：修改conf/settings.xml 中的 <localRepository> 为一个指定目录
* <code style="font-size: 18px; font-family: Microsoft YaHei;"> <localRepository>D:\maven</localRepository> </code>

#### 3. 配置阿里云私服： 修改conf/settings.xml 中的 <mirrors> 标签，为其添加如下子标签：
<pre>
<code style="font-size: 18px; font-family: Microsoft YaHei;">
        <mirror>
            <id>alimaven</id>
            <name>aliyun maven</name>
            <url>https://maven.aliyun.com/repository/public</url>
            <mirrorOf>central</mirrorOf>
        </mirror>
</code>
</pre>

#### 4. 配置环境变量：MAVEN_HOME 为maven的解压目录，并将其bin目录加入 PATH 环境变量
* 右键点击“此电脑” → 选择“属性” → 点击“高级系统设置” → 在“高级”选项卡中点击“环境变量”。

* MAVEN_HOME： D:\software\apache-maven-3.6.3
* PATH添加： %MAVEN_HOME%\bin

#### 5. 测试
* mvn -v
