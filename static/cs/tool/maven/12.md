### 操作
#### 1. 配置setting.xml
* D:\software\apache-maven-3.6.3\conf\setting.xml

#### （1） 在servers标签中，配置访问私服的个人凭证（访问的用户名和密码）
```
    <server>
        <id>releases</id>
        <username>...</username>
        <password>...</password>
    </server>

    <server>
        <id>snapshots</id>
        <username>...</username>
        <password>...</password>
    </server>
```

#### （2） 在mirrors中只配置我们自己私服的连接地址（如果之前配置过阿里云，需要直接替换掉）
```
    <mirror>
       <id>...</id>
       <name>...</name>
       <url>...</url>
       <mirrorOf>...</mirrorOf>
    </mirror>
```
#### （3） 在profiles中，增加如下配置，来指定snapshot快照版本的一眼，依然允许使用
```
    <profile>
        <id>snapshots</id>
        <repositories>
            <repository>
                <id>central</id>
                <url>...</url>
                <releases>
                    <enabled>true</enabled>
                    <updatePolicy>always</updatePolicy>
                </releases>
            </repository>
        </repositories>
        <pluginRepositories>
            <pluginRepository>
                <id>nexus-plug</id>
                <name>local private nexus-plug</name>
                <url>...</url>
            </pluginRepository>
        </pluginRepositories>
    </profile>
```

#### 2. pom
```
    <distributionManagement>
        <repository>
            <id>releases</id>
            <url>http://.../releases</url>
        </repository>
        <snapshotRepository>
            <id>snapshots</id>
            <url>http://.../snapshots</url>
        </snapshotRepository>
    </distributionManagement>
```

#### 3. mvn clean deploy
