#### Using Json Server
#### 1. data/db.json
```
    {
      "blogs": [
        {
          "id": 1,
          "title": "My First Blog",
          "author": "tom",
          "body": "Hello, everyone..."
        },
        {
          "id": 2,
          "title": "The beautiful color",
          "author": "Jean",
          "body": "Green, red, blue"
        }
      ]
    }
```

#### 2. 启动命令： npx json-server --watch data/db.json --port 8001
#### 3. 测试： curl 'http://localhost:8001'
