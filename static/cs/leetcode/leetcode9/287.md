#### 287. 寻找重复数
```
    class Solution {
        public int findDuplicate(int[] nums) {
            while(nums[0] != nums[nums[0]]) {
                swap(nums, 0, nums[0]);
            }
            return nums[0];
        }

        public void swap(int[] nums, int i, int j) {
            int t = nums[i];
            nums[i] = nums[j];
            nums[j] = t;
        }
    }
```
