#### 152. 乘积最大子数组
```
    class Solution {
        public int maxProduct(int[] nums) {
            int max = 1;
            int min = 1;
            int ans = Integer.MIN_VALUE;
            for(int num : nums) {
                int a = max * num;
                int b = min * num;
                max = Math.max(num, Math.max(a, b));
                min = Math.min(num, Math.min(a, b));
                ans = Math.max(ans, max);
            }
            return ans;
        }
    }
```
