### 20.有效的括号

```
    class Solution {
        public boolean isValid(String s) {
            while(s.length() != 0) {
                int ori = s.length();
                s = s.replace("()", "");
                s = s.replace("[]", "");
                s = s.replace("{}", "");
                if(ori == s.length()) {
                    return false;
                }
            }
            return true;
        }
    }
```
