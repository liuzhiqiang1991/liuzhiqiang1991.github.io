### windows安装mysql
* 官网下载地址：https://dev.mysql.com/downloads/installer/
* 下载： mysql-installer-community-8.0.42.0.msi
#### 1. 双击执行安装
#### 2. 启动与停止
* 运行 ——> services.msc ——> 启动/停止

#### 3. 客户端连接
* 配置环境变量 MYSQL_HOME: D:\software\mysql-8.0.26-winx64
* 配置PATH环境变量: %MYSQL_HOME%\bin

* 命令行执行： mysql [-h 127.0.0.1] [-P 3306] -u root -p
