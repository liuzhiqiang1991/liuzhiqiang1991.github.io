### DDL
#### 数据库操作
* 查询所有数据库：show databases;

* 查询当前数据库：select database();
* create database [if not exists] 数据库名 [default charset utf8mb4];
* 删除： drop database [if exists] 数据库名;
* 使用： use 数据库名;

#### 表操作
* 查询当前数据库所有表： show tables;

* 查询表结构： desc 表名;
* 查询建表语句： show create table 表名;
