#### 设计mapping：商品Mapping映射
#### 1. 分析：要实现商品搜索，索引库的字段要满足页面搜索的需求
* 主键，需要存储，需要索引

* 搜索字段，需要存储，需要索引（名称、分类、品牌、价格）
* 排序字段，需要存储，需要索引（价格、销量、更新时间）
* 展示字段，需要存储         （图片、评价）
* isAD(是否广告)，需要存储，需要索引

#### 2. 设计索引库
```
    # 商品索引库
    PUT /items
    {
      "mappings": {
        "properties": {
          "id": {
            "type": "keyword"
          },
          "name": {
            "type": "text",
            "analyzer": "ik_smart"
          },
          "price": {
            "type": "integer"
          },
          "image": {
            "type": "keyword",
            "index": false
          },
          "category": {
            "type": "keyword"
          },
          "brand": {
            "type": "keyword"
          },
          "sold": {
            "type": "integer"
          },
          "commentCount": {
            "type": "integer",
            "index": false
          },
          "isAD": {
            "type": "boolean"
          },
          "updateTime": {
            "type": "date"
          }
        }
      }
    }
```
