#### 文档CRUD
#### 1. 新增文档
```
    POST /test/_doc/1
    {
        "info": "测试数据输入",
        "email": "tom@163.com",
        "name": {
            "firstName": "tom",
            "lastName": "格林"
        }
    }
```

#### 2. 查询文档：  GET /test/_doc/1
#### 3. 删除文档：  DELETE /test/_doc/1

#### 4. 修改文档
* 全量修改（同时具备新增/修改功能）
```
    POST /test/_doc/1
    {
        "info": "测试数据输入2",
        "email": "tom@163.com",
        "name": {
            "firstName": "tom",
            "lastName": "格林"
        }
    }
```

* 增量修改
```
    POST /test/_update/1
    {
      "doc": {
        "email": "tom2@163.com"
      }
    }
```
