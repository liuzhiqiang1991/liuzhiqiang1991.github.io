### 索引库的CRUD
#### 1. 创建索引库和映射
```
    PUT /test
    {
      "mappings": {
        "properties": {
          "info":{
            "type": "text",
            "analyzer": "ik_smart"
          },
          "email":{
            "type": "keyword",
            "index": "false"
          },
          "name":{                  // 字段名
            "type": "object",
            "properties": {
              "firstName": {        // 子字段名
                "type": "keyword"
              },
              "lastName": {         // 子字段名
                "type": "keyword"
              }
            }
          }
        }
      }
    }
```

#### 2. 查询索引库： GET /test
#### 3. 删除索引库： DELETE /test
#### 4. 修改索引库
* 索引库和mapping一旦创建无法修改，但是可以添加新的字段
```
    PUT /索引库名/_mapping
    {
      "properties": {
        "age":{
          "type": "integer"
        }
      }
    }
```
