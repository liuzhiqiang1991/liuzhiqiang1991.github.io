<font color="#dd00dd" size=5>Mapping属性</font><br />

* mapping 是对索引库中文档的约束

#### 1. type：字段数据类型
* 字符串：text（可分词的文本）、keyword（精确值，例如：品牌、国家、IP地址）
* 数值：byte、short、integer、long、float、double
* 布尔：boolean
* 日期：date
* 对象：object
#### 2. index：是否创建索引，默认为true
#### 3. analyzer：使用哪种分词器
#### 4. properties：该字段的子字段
