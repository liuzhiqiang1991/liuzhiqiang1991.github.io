### 性能分析-show profiles
* show profiles 能够在做SQL优化时帮助我们了解时间都耗费到哪里去了。
* 查看当前MySQL是否支持profile操作： select @@have_profiling;
* 检查profile是否打开：select @@profiling; （0表示关闭，1表示打开）
* 打开profile功能： set profiling=1;

* 当前会话，查看每一条SQL的耗时情况： show profiles;
* 查看指定query\_id的SQL语句各个阶段的耗时情况： show profile for query query_id;
* 查看指定query\_id的SQL语句CPU的使用情况： show profile cpu for query query_id;
