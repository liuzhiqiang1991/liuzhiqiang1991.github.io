### 叶子查询
#### 1. 全文检索查询
#### 1.1 match
```
    GET /demo/_search
    {
      "query": {
        "match": {
          "name": "7"
        }
      }
    }
```
#### 1.2 multi_match
```
    GET /demo/_search
    {
      "query": {
        "multi_match": {
          "query": "7",
          "fields": ["name", "price"]
        }
      }
    }
```

#### 2. 精确查询
#### 2.1 term: 根据词条精确匹配，一版搜索keyword类型、数值类型、布尔类型、日期类型字段
```
    GET /demo/_search
    {
      "query": {
        "term": {
          "price": {
            "value": "17"
          }
        }
      }
    }
```

#### 2.2 range：根据数值范围查询，可以是数值、日期的范围
```

    GET /demo/_search
    {
      "query": {
        "range": {
          "price": {
            "gte": "16",
            "lte": "17"
          }
        }
      }
    }
```

#### 2.3 ids
```
    GET /demo/_search
    {
      "query": {
        "ids": {
          "values": ["1", "2", "3"]
        }
      }
    }
```
