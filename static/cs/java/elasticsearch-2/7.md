### 高亮显示
* 高亮显示：就是在搜索结果中把搜索关键字突出显示。

#### 1. 语法
```
    GET /demo/_search
    {
      "query": {
        "match": {
          "name": "测试"
        }
      },
      "highlight": {
        "fields": {
          "name": {               // 指定要高亮的字段
            "pre_tags": "<em>",   // 高亮的前置标签
            "post_tags": "</em>"  // 高亮的后置标签
          }
        }
      }
    }
```
