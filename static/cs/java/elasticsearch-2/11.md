### 排序和分页（api）
```
    @Test
    void testPageAndSort() throws IOException {
        int pageNo = 1, pageSize = 3;

        // 1.创建Request
        SearchRequest request = new SearchRequest("demo");
        // 2.组织请求参数

        request.source().query(QueryBuilders.matchQuery("name", "测试"));   // 搜索条件
        request.source().sort("sold", SortOrder.DESC)
                        .sort("price", SortOrder.ASC);                      // 排序
        request.source().from((pageNo - 1) * pageSize).size(pageSize);      // 分页

        // 3.发送请求
        SearchResponse response = client.search(request, RequestOptions.DEFAULT);
        // 4.解析响应
        handleResponse(response);
    }
```
