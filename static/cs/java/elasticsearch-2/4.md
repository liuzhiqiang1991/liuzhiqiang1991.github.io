### 排序和分页
#### 1. 排序
* elasticsearch 支持对搜索结果排序，默认是根据相关度算分（_score）来排序，也可以指定字段排序。
* 可以排序字段类型有：keyword类型、数值类型、地理坐标类型、日期类型等。

#### 2. 排序示例： 搜索商品，按照销量排序，销量一样则按照价格升序
```
    GET /demo/_search
    {
      "query": {
        "match_all": {}
      },
      "sort": [
        {
          "sold": "desc"
        },
        {
          "price": "asc"
        }
      ]
    }
```
