### 配置多环境
#### 1. 项目初始化
#### 2. 打包插件
```
    <build>
        <finalName>demo</finalName>
        <plugins>
            <plugin>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-maven-plugin</artifactId>
            </plugin>
        </plugins>
    </build>
```

#### 3. application.yaml
```
    spring:
      profiles:
        active: dev
```

#### 4. application-dev.yaml, application-test.yaml, application-prod.yaml 配置启动端口

#### 5. 测试
* mvn clean package

* java -jar -Dspring.profiles.active=dev target/demo.jar
* java -jar -Dspring.profiles.active=test target/demo.jar
